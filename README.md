#### Currently building

**[Ranch](https://github.com/Bramvanosta/Ranch)**: a desktop client for BullMQ queues. See what is waiting, running and failing, drill into a job, retry or clean up, and let your AI agents do the same through its built-in MCP server, under your control. macOS and Linux.

```sh
brew install --cask bramvanosta/tap/ranch@beta
```

**[Retake](https://github.com/Bramvanosta/Video)**: turns a written scenario into a finished product video. It plays your web app in a headless browser with the cursor drawn in the page, edits the take in your theme, and lets your AI agents write and run it all through its MCP server. A macOS app for Apple silicon, or from the source on Linux.

```sh
brew install --cask bramvanosta/tap/retake
```
